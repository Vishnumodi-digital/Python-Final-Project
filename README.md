# World Happiness Report Analysis

## Project Overview

This project analyzes the World Happiness Report dataset using Python, Pandas, Matplotlib, and Seaborn. The goal is to identify factors that influence happiness levels across countries and visualize relationships between happiness scores and socio-economic indicators.

---

## Objectives

* Analyze global happiness scores.
* Identify the happiest and least happy countries.
* Study the impact of GDP, social support, and life expectancy on happiness.
* Create meaningful visualizations using Seaborn.
* Perform correlation analysis between variables.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Dataset

The dataset contains information about:

* Country
* Happiness Score
* GDP per Capita
* Family (Social Support)
* Health (Life Expectancy)
* Freedom
* Trust (Government Corruption)
* Generosity

Dataset Source:

[World Happiness Report Dataset](https://www.kaggle.com/datasets/unsdsn/world-happiness?utm_source=chatgpt.com)

---

## Data Preprocessing

* Loaded dataset using Pandas
* Checked data types and missing values
* Generated summary statistics
* Created Happiness Categories:

  * Low
  * Medium
  * High

## Key Findings

* Countries with higher GDP tend to have higher happiness scores.
* Social support is strongly associated with happiness.
* Better life expectancy contributes positively to happiness.
* Nordic countries consistently rank among the happiest nations.
* Economic and social factors play significant roles in determining happiness.

---

## Conclusion

The analysis demonstrates that happiness is influenced by multiple factors including economic prosperity, social support, and health conditions. Visualization techniques helped uncover meaningful relationships and trends within the dataset.
